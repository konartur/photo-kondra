# PF-UX-09 — Списки фотосесій та історій

**Статус:** Заплановано.
**Залежить від:** PF-UX-08.
**Порядок і правила:** [PF-UX-00](PF-UX-00-INDEX.md).
**Вимоги:** [UX-план](docs/portfolio-content/admin-ux-plan.md).

## Початок роботи

Прочитати індекс перед змінами. Орієнтири для огляду актуального коду: portfolio-workspace.tsx; admin summary/list DTO, services, BFF за потреби.

## Обсяг

1. Замінити «Вибрати запис» списком із мініатюрою, назвою, статусом, індикатором неопублікованих змін та «Відкрити».
2. Угорі розмістити «Додати фотосесію» / «Додати історію», пошук і фільтри «Усі / Чернетки / Опубліковані / Архів».
3. Підтримати пагінацію; пошук і фільтр виконувати над усіма записами, мінімально розширивши чинний API/Swagger, якщо потрібно.
4. Використовувати захищену мініатюру та явний placeholder для неповної чернетки без назви/обкладинки.
5. Зберігати пошук, фільтр і повернення зі сторінки редагування. Окремі loading/error/empty стани, дієві повторні спроби.

## Критерії приймання

- [ ] Запис можна впізнати до відкриття редактора.
- [ ] Фільтри й пошук узгоджені з cursor/query keys.
- [ ] Список адаптивний та доступний клавіатурою.

## Межі

Не змінювати модель фотосесій та історій, не додавати масові операції.

## Перевірки

За вказівкою власника запуск тестів, lint, typecheck, build і браузерне QA відкладено до [PF-UX-14](PF-UX-14-final-acceptance.md). На цьому кроці — огляд коду й diff та запис сценаріїв для фіналу. Критерії вище описують цільову поведінку; їх остаточне підтвердження виконується у PF-UX-14.
