# PF-UX-13 — Візуальне кадрування та доступні деталі фото

**Статус:** Заплановано.
**Залежить від:** PF-UX-12.
**Порядок і правила:** [PF-UX-00](PF-UX-00-INDEX.md).
**Вимоги:** [UX-план](docs/portfolio-content/admin-ux-plan.md).

## Початок роботи

Прочитати індекс перед змінами. Орієнтири для огляду актуального коду: editor-fields.tsx/ImageRef; спільний редактор параметрів зображення.

## Обсяг

1. Замінити основні числові X/Y керуванням точкою кадрування поверх фото. Зберегти чинні нормалізовані координати 0–1.
2. Додати клавіатурне переміщення точки, скидання до автоматичного центру та зрозумілий стан увімкнення. Перетягування не є єдиним способом.
3. Врахувати реальний розмір видимого зображення й object-fit, щоб координати не зсувалися через порожні поля контейнера.
4. Alt підписати «Опис зображення для доступності», дати короткий приклад; залишити обидві мови та фокус на помилці.
5. Використати один компонент у всіх контекстах, не змінювати оригінальний файл.

## Критерії приймання

- [ ] Місце кадрування обирається на самому фото мишею, дотиком і клавіатурою.
- [ ] Збережені раніше координати відображаються коректно.
- [ ] Alt і focalPoint залишаються контекстними, а не глобальними для файла.

## Межі

Не додавати редактор зображень, фізичне обрізання чи нові медіаваріанти.

## Перевірки

За вказівкою власника запуск тестів, lint, typecheck, build і браузерне QA відкладено до [PF-UX-14](PF-UX-14-final-acceptance.md). На цьому кроці — огляд коду й diff та запис сценаріїв для фіналу. Критерії вище описують цільову поведінку; їх остаточне підтвердження виконується у PF-UX-14.
