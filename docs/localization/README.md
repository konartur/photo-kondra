# Локалізація Photo Cloud: українська та англійська

**Дата рішення:** 2026-11-20. **Стан:** погоджено власником; підготовлено тікети та довідкові DTO, runtime ще не реалізовано.

## Погоджені вимоги

- Дві мови всього сайту: `uk` та `en`. Портфоліо, бронювання, login/auth, dashboard, приватні галереї, помилки, validation, loading/empty/retry, status, alt/aria та metadata входять до обсягу.
- Тексти інтерфейсу та початкове статичне портфоліо мають готові словники у коді. Завантажувати тільки потрібну локалізацію; жодного машинного перекладу під час перегляду.
- Редагований контент зберігається двома мовами в БД. Перемикач обирає готову версію, а не створює переклад. Автор заповнює обидві версії через адмінку.
- URL `/uk/...` та `/en/...`; slug та token однакові для обох мов. Старі URL залишаються доступними через перенаправлення. `/api/...`, auth callbacks і storage URLs не отримують префіксів мови.
- Пріоритет: мова в URL → збережений вибір браузера → `Accept-Language` → `en`. Враховувати quality weights, `uk-UA`, `en-*`, `q=0` та непідтримувані мови. Українська, якщо найкраща підтримувана перевага — `uk`; інакше англійська. Ручний вибір запам'ятовується cookie, доступною SSR; явний мовний URL визначає поточну сторінку, не залежить від cookie.
- `UK / EN` у навігації кожної частини сайту та на мобільному. Мова відображення української — `uk`, не `ua`. Перемикання зберігає маршрут/query/hash, фото, дані форм і активні uploads; не переносити приватні дані у URL.
- Нові галереї: title обома мовами обов'язковий; description необов'язковий, але якщо заданий, потрібні обидві версії. Старий контент тимчасово показувати в обох мовах до ручного перекладу.
- Ціни в UAH без конвертації. Дати/числа/кількість/одиниці локалізуються, включно з українськими множинами. Власні імена й filename автоматично не перекладаються; ключі сховища й оригінали не змінюються.

## Перетин з контентом портфоліо

Поточний сайт має статичний контент; L10N-03 перекладає його, не очікуючи CMS. Майбутні [DTO портфоліо](../portfolio-content/dto-contracts.ts) вже враховують локалізацію. PF-CONTENT-01/02/04/05/06/06A/07/08/09/10 мають реалізувати двомовні поля, атомарну публікацію, locale-aware reader/cache/editor/import відповідно до цих контрактів. Це доповнення вимог, а не реалізація CMS у L10N-03. Якщо CMS реалізують першою — використовувати її двомовний reader замість другого джерела контенту.

## Правила виконання

Прочитати AGENTS.md і застосовні вкладені правила. Для Next.js — локальні framework docs. Реалізувати малими змінами в поточному модульному моноліті. Зберегти auth/BFF, noindex приватних сторінок, приватність storage та токенів. Не послаблювати validation або authorization для міграції. Типи з цього каталогу є специфікацією, не готовими NestJS DTO.

Кожен тікет потребує цільових тестів, lint/typecheck/build змінених частин; перед закриттям — unit та релевантні E2E за AGENTS.md. Записувати фактичні результати й блокери в тікеті. Не запускати deployment, DNS/TLS або production migrations: hosting відкладено окремим рішенням. Створення цього плану не означає завершення тікетів.
