## Підтверджені рішення

Власник підтвердив модель за підсумками квізу 2026-11-20: один напрям має багато історій; чернетка відокремлена від публікації; slug після першої публікації незмінний; використаний контент захищений від видалення. Медіа портфоліо незалежні від Photo Cloud. [Запис рішень](decisions.md) визначає медіаліміти, Redis-кеш та імпорт. Це погоджений план, а не вже реалізовані можливості.

Існуючі /stories/love, portrait, family, events, brand, pets залишаються історіями з тими самими URL. Окремі напрями мають власні ID; нові публічні сторінки /services/* у цьому плані не додаються. DTO напряму придатний для майбутньої сторінки або добірки.

## Зміна попереднього рішення

Чинне [рішення про домен](../portfolio-domain-decision.md) задає public/portfolio/ для першого запуску. Цей пакет описує наступний етап — керований у БД контент і приватне object storage. До перевіреного перемикання діє поточна реалізація. Домен, /g/*, ingress, BFF і відкладення деплою цим планом не змінюються.

Проєктування [TD-PF-12](../technical-debt/portfolio/12-database-content-design.md) завершене й підтверджене власником. Імплементація виконується окремо за 11 послідовними тікетами, включно з обов’язковим PF-CONTENT-06A для Redis.


## Узгодження з локалізацією

[Окремий план L10N](../localization/README.md) додає uk/en до всіх редакційних текстів портфоліо. Довідкові DTO вже оновлено; runtime ще не реалізовано. Збереження шести URL означає сумісні перенаправлення на /uk/... чи /en/... без зміни slug. Приватні галереї локалізуються окремими L10N-04/05/06, не через PortfolioModule.
