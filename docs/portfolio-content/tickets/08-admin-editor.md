## Інструкції агенту

Прочитати [спільні правила](README.md#правила-виконання), [архітектуру](../architecture.md) і [DTO-специфікацію](../dto-architecture.md).

1. Додати окрему навігацію портфоліо в dashboard без зміни gallery workflow; при UI роботі застосувати ui-ux-pro-max і локальні Next.js docs.
2. Побудувати форми напрямів, історій, головної/контактів, upload і вибору медіа та порядок фото. Показати ліміт 10 на історію і вхідні JPEG/PNG/WebP до 10 МБ; загальну кількість фото не обмежувати.
3. Показувати saved draft, published version, unsaved edits і явні publish/archive; обробляти 409 version conflict без втрати введеного.
4. Preview доступний лише чинній адмінській сесії; використати admin media routes. Валідаційні помилки прив’язати до полів.
5. Сценарій зйомочної заявки залишити локальним; редактор не додає зберігання клієнтських заявок.
