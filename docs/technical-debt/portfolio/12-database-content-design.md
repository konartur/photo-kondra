# TD-PF-12 — Спроєктувати перенесення контенту портфоліо в БД

**Статус:** Завершено проєктування; власник підтвердив рішення 2026-11-20. Реалізація БД/API/адмінки не розпочата.
**Пріоритет:** P1 — архітектура та керованість.

## Проблема та область роботи

Контент зашитий у коді й вимагає перебудови frontend. Завдання цього тікета — погодити модель і підготувати конкретний план міграції лише модуля портфоліо.

## Залежності

Власник підтвердив [рішення](../../portfolio-content/decisions.md). Враховано технічні пропозиції TD-PF-01/02/03/04/07/08/09; решта техборгу не вважається виконаною автоматично.

## Інструкції агенту

1. Використовувати [архітектуру](../../portfolio-content/architecture.md), [DTO](../../portfolio-content/dto-architecture.md) та [довідкові TypeScript-контракти](../../portfolio-content/dto-contracts.ts).
2. Реалізацію починати з [PF-CONTENT-01](../../portfolio-content/tickets/01-dto-contracts.md) і виконувати [11 тікетів послідовно](../../portfolio-content/tickets/README.md). Redis PF-CONTENT-06A обов’язковий.
3. Ліміт — 10 фото на історію; загальна бібліотека зростає понад базові 21 фото. Імпорт включає всі існуючі демодані. Реальне наповнення — через готову адмінку наприкінці.
4. Зберігати приватні галереї, чинні auth/BFF та відкладення деплою. Кожен імплементаційний тікет має власні перевірки; завершення цього не означає готовий runtime.

## Критерії приймання

- [x] Модель напрямів/історій, окрема чернетка, slug і захист посилань погоджені.
- [x] Описано storage/media, lifecycle, public/admin DTO та API.
- [x] Redis-кеш, invalidation/retry і PostgreSQL fallback включені до архітектури.
- [x] Є інвентаризація 21 фото, план імпорту/відкату та послідовні тікети.
- [x] Власник підтвердив підсумок; реалізація винесена в окремі задачі.

## Перевірка

Проєктні критерії перевірені за рішеннями квізу та перехресними посиланнями документації. Runtime-тести цього дизайну ще не виконувалися; вони є критеріями імплементаційних тікетів.

## Поза областю роботи

Виконання міграцій, реалізація API, завантаження файлів, адмінка та деплой.
