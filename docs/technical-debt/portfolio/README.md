## Наступний крок і порядок виконання

Після обговорення TD-PF-12 підготовлено [DTO-архітектуру та план перенесення](../../portfolio-content/README.md) і [11 послідовних тікетів](../../portfolio-content/tickets/README.md). Реалізація БД ще не розпочата. Перед виконанням врахувати підтверджені [рішення](../../portfolio-content/decisions.md) пакета та його карту перетинів техборгу; не будувати одночасно файлову CMS і DB-модель.

Для незалежних робіт немає глобальної залежності від БД. Спочатку зняти базу [TD-PF-11](11-performance-baseline.md) перед оптимізаціями viewport і layouts. Уточнити модель кадрів TD-PF-02 разом із посиланнями TD-PF-01. Після змін виконати відповідні перевірки TD-PF-09/10. Кожен тікет містить конкретні жорсткі та координаційні залежності.

## Правила виконання

1. Прочитати [AGENTS.md](../../../AGENTS.md), інструкції у змінюваних каталогах і пов’язані початкові тікети. Для Next.js до написання коду прочитати відповідні локальні матеріали у frontend/node_modules/next/dist/docs/.
2. Перед змінами звірити проблему з актуальним кодом. Наведені спостереження — статичний аналіз, а не результат нового запуску тестів чи вимірювань.
3. З’ясувати статус залежностей. Відрізняти зовнішній блокер від частини задачі, яку можна виконати незалежно; відкриту частину явно залишити незавершеною.
4. Впроваджувати лише область обраного тікета. Зберігати модульний моноліт, приватність клієнтських фото та погоджений локальний сценарій копіювання заявки.
5. Для змін коду виконати lint, typecheck, цільові регресії та build відповідно до AGENTS.md і фактичних scripts package.json. Нові тести мають перевіряти поведінку/інваріанти, а не повторювати реалізацію. Для суто документаційних змін перевірити посилання та узгодженість залежностей.
6. Завершуючи, записати фактичні перевірки, результат критеріїв приймання й невирішені блокери. Оновити пов’язаний початковий тікет, якщо робота закриває його критерії; єдину реалізацію не рахувати двічі.
7. Цей backlog не є інструкцією до деплою. Чинне відкладення hosting/deployment залишається в силі.
